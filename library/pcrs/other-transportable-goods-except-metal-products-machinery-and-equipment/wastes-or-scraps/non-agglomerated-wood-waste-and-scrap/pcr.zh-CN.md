# 锯材加工产生的非团聚自然含水北欧云杉锯屑

## 1. 范围与适用性

本方法覆盖将未化学处理、自然含水的北欧云杉锯材原木锯成锯材时产生的一股实物分收松散锯屑，包括来源联合锯切、必要分离及供后续利用的首次质量放行。产品为实测自然含水状态的细锯缝锯屑，以散装供货，不经过工业热干燥、加黏结剂、化学处理或加压团聚。声明的验收规格必须按实际筛分分布和颗粒形态区分较粗锯木厂木片及刨花；不虚构统一筛孔限值或含水数值。普通输送或临时装袋不属于团聚。对象仅为 UN CPC 3.0 39283 中的锯屑子集，不是所有非团聚废木形态（`un-cpc3-2025`）。

技术综合分别采用真实北欧云杉锯木厂及副产物背景（`metsa-renko-sawmill`）、独立的湿锯屑供货和较粗木片区分原件（`sodra-sawdust`），并核对独立的锯木与木材测量方法。并不声称这些来源属于同一供方、当代订单、工厂配方或共用实测绩效。其中含水、能值、灰分、密度、得率和分配实例均不是默认值。具体数据集须证明自己的云杉身份、分收、未处理状态、含水与供货门。

排除颗粒（39281）、木压块及其他团聚形态（39282）、专门粉碎至填料等级的木粉、粗木片、薄片/刨花、树皮产品、混合碎木燃料、以原生锯材作为参考产品、消费后木材、MDF/OSB 等胶合复合板残余、涂漆/防腐或其他污染木材。不得将这些形态混成未来选择器。其他树种、干锯屑路线、化学污染、现场燃料动力设备、锅炉或干燥器须先明确范围并补全原子清单再使用；不能用零值行否认实际路线差异。

### 阶段门与实物核对

来源链为原木接收 → 实际剥皮 → 锯切/齐边/截断 → 细锯屑分收 → 实际安装的筛杂/抽吸 → 首次放行 Q_c → 仓储/临时容纳 → 散装装车/发运。对未干燥锯材、粗木片和树皮保留独立实测的联产品切分；它们不是可替换的参考产品。仅在真实验收规格允许时回用捕集细锯屑。重复通过消耗真实能量和资源。实际锅炉/热干燥/化学处理属于范围变化，不能静默省略。

对每个实测组分 k（干木、树皮、普通水、各辅助组分和独立实测的相关元素），生产门为：期初 WIP_k + 新鲜投入_k = 期末 WIP_k + 新增放行_k + 联合输出_k + 生产废物_k + 生产排放_k。放行水和干质量有各自实测状态。已放行成品就在新增放行项内，故本式不能再加期末 FG。服务门为：期初 FG_k + 放行_k + 外部退回_k = 期末 FG_k + 毛发运_k + 服务废物_k + 服务排放_k。抵消共同放行转移得到合并门，保留同一实物项和库存状态。真实发生转化时，先独立证明并纳入反应物/产物（包括真实耗氧或反应水）再求闭合；本电动机械路线不虚构化学反应。残差是带不确定性的披露缺口，绝不能成为两个拟合未知数或自动某种气体。

每种包装制品 p 均用：期初空包装 + 期初附着 WIP/FG 包装 + 期初周转存量 + 新购 P_p + 首次外部非采购实物接收 N_ext,p + 真实外部返回收到 ER_p = 期末空包装 + 期末附着 WIP/FG 包装 + 期末周转存量 + 随毛实物发运包装 S_p + 对外返还 EO_p + 废物 W_p。每次接收的 P_p、N_ext,p 与 ER_p 互斥。N_ext,p 包含真正未随整批采购取得的首次借入、租入或随货组件；整批采购中已取得但未单独开票的组件仍属 P_p。ER_p 须有同一组件先前真实对外发运的记录。每个实际缺失的非购实收均须增设具体材料、形态、类型和投入方向的原子界面，配实测原始数量、接收与保管及原批次，以及所有者、继承向量和供应方证据；仅采购卡仍仅表示采购。实物接收与库存本身不产生新制造采购或负荷。一个真实所有者和供应方贡献只计一次，保留未用库存原历史，仅加真实新增服务；不复制整批负荷、不造信用或新 Q_c。实物质量基准相同，去除库存位置重叠。内部复用/转移抵消，不形成新 P_p、产品净 Q_c 或自动联产品。散装供货 S_p 可为实测零，但临时服务容器、磨耗及外部移动仍须记账。新增项必须有真实新事件；已证明同侧重复时应删同侧确切重复，不能虚构对侧补平流。整份混合废水/油/包装出口和组成子账是同一实物交换的非叠加表达，只用一个真实供方。
