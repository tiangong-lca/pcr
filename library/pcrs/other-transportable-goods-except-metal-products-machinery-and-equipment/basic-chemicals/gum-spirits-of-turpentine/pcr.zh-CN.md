# 脂松节油：采割松脂蒸汽蒸馏及盐床脱水

## 1. 范围与适用性

本 PCR 只覆盖一条制造路线：活松树采割松脂经预处理及蒸汽蒸馏、油水分离、氯化钠盐床脱水和散装储存装车得到整品脂松节油。参考为供货混合物，不是分离的α-蒎烯、β-蒎烯或树脂酸组分。FAO 与 EPA 将此路线同树桩溶剂萃取、破坏性蒸馏及硫酸盐法回收区分（fao-gum-1995；epa-gum-1976）。须记录实际设备、材料、质量和供方参考；历史工厂观察和通用流身份均不规定配方。

排除妥尔油及其馏分、硫酸盐法或木材及破坏性蒸馏松节油、树桩溶剂萃取、纯萜烯化学品分馏、配制清洗剂、松油、松香衍生物和活化矿物。脂松香是本工序真实共产品，保留独立实物出口及负荷份额，不构成第二个独立编写 PCR。原生整品松节油流仅可结合真实脂源、等级和供方使用；宽身份不证明路线、质量、组成或供方清单。

前景为一个聚合，另保留分阶段计量账：（a）接收并净称松脂，按实际安装用可追踪回用松节油熔脂稀释、调理过滤洗涤并返处理乳化层；（b）区分间接及喷入蒸汽进行蒸馏，截留夹带物、冷凝及油水分相，并排出整品松香；（c）油经过实际盐床，核算盐水及滞留油；（d）储存、验收和散装装车。未使用的条件行须有未用证据，不得假定为零。新增实际介质、化学品、包装组件、物种或出口必须逐项设原子卡并审查实物去向。不采用来源案例的用量、收率、温压、时间、剂量或纯度范围（fao-gum-1995；epa-gum-1976）。

本路线使用真实连接生产者外供的电力和水蒸汽。现场锅炉、燃料燃烧、火炬及 VOC 热破坏不属于该限定前景。实际存在时，不得将燃料或排放藏在身份不明的热投入内：应扩展并审查模型，逐一列出实际燃料、燃烧空气或氧气、水、排放物种、灰和有用热接口；或采用独立完整建模的真实公用工程或处理生产者，并匹配转移参考。直接环境水排放及外部捕集气处理同样需要真实接收方、介质和完整连接。

分配之前逐阶段核对整品湿重：期初库存 + 真实外部接收 + 成对内部接收 = 期末库存 + 真实外部实物出口 + 成对内部转移。另核对水平衡，包括松脂自带水、直接蒸汽、洗涤水、盐床水、冷凝水、液体排流、产品水、蒸发和库存滞留。逐个实测组分或元素 X 使用S0_X + I_X + G_X = S1_X + O_X + C_X，其中 S0_X 和 S1_X 为期初期末组分库存，I_X 和 O_X 为真实投入产出，G_X 和 C_X 为真实生成消耗；元素没有化学生成消耗，反应物种则须记录对应项。记录真实氧化降解，不假定整品为纯 C10H16。GC 峰面积百分比不自动等于整品质量分数。未知组分、水和不挥发物须显式保留，未测余量不得变成α-蒎烯。技术废物保留整股混合流质量及分析组分负荷，后者不得再次成为额外交换。

Q 锁定为声明批群及厂门的唯一真实首次验收净质量之和。重复质检、退货、稀释油循环、重蒸和再验收不产生新事件。Q 是整品验收量，不是干萜烯质量、蒎烯含量、罐区总周转量、发运量或第二个外部实物产出。在观察截止时，将原验收质量基准划分为互斥状态：记录退货后的最终外部交付、留存成品、隔离、返工在制、外部降级处置、取样及不可逆验收后损失。以父事件追踪退货返工，使每一克仅有一个当前去向；外部新增物及负荷另列。不得将已损失原质量还原给存活余量后又计一次损失。仅当不存在其他厂门后出口、损失或留存状态时，才能使用 Q = 交付 + 新增成品库存；否则须完整核对互斥状态。来源库存桥未闭合时数据集不完整。该批群后续储存装车服务继续使用原 Q。

覆盖原料、在制品、稀释油及已验收品的期初期末库存和真实批群。期初在制品继承既有前景工作及材料历史，不得当作无负荷新松脂。供方已含负荷只继承一次，仅追加新工作，不重复此前供方已含的熔脂或蒸馏。内部油和乳化层保留实物转移库存史，不是额外外购物或零信用残余出口。外购开车油和旧验收库存同新增松脂回收物分开追踪。完整清单要求继承和当期供方基准一致，不能仅凭期间净采购总量。

## 7. 分配与共产品处理

## 9. 校验规则

检查以下完整方法单元及其条件，不得仅摘取孤立规则 ID。

1. 确认真实活松脂源和准确蒸汽蒸馏盐床脱水路线、整品液体混合物状态、实际等级供方及全部 ASCII 限定。拒绝木源、硫酸盐法、破坏性蒸馏、妥尔油、分离蒎烯和配制品替代。

2. Q 锁定为声明批群及厂门的唯一真实首次验收净质量之和。重复质检、退货、稀释油循环、重蒸和再验收不产生新事件。Q 是整品验收量，不是干萜烯质量、蒎烯含量、罐区总周转量、发运量或第二个外部实物产出。在观察截止时，将原验收质量基准划分为互斥状态：记录退货后的最终外部交付、留存成品、隔离、返工在制、外部降级处置、取样及不可逆验收后损失。以父事件追踪退货返工，使每一克仅有一个当前去向；外部新增物及负荷另列。不得将已损失原质量还原给存活余量后又计一次损失。仅当不存在其他厂门后出口、损失或留存状态时，才能使用 Q = 交付 + 新增成品库存；否则须完整核对互斥状态。来源库存桥未闭合时数据集不完整。该批群后续储存装车服务继续使用原 Q。

3. 分配之前逐阶段核对整品湿重：期初库存 + 真实外部接收 + 成对内部接收 = 期末库存 + 真实外部实物出口 + 成对内部转移。另核对水平衡，包括松脂自带水、直接蒸汽、洗涤水、盐床水、冷凝水、液体排流、产品水、蒸发和库存滞留。逐个实测组分或元素 X 使用S0_X + I_X + G_X = S1_X + O_X + C_X，其中 S0_X 和 S1_X 为期初期末组分库存，I_X 和 O_X 为真实投入产出，G_X 和 C_X 为真实生成消耗；元素没有化学生成消耗，反应物种则须记录对应项。记录真实氧化降解，不假定整品为纯 C10H16。GC 峰面积百分比不自动等于整品质量分数。未知组分、水和不挥发物须显式保留，未测余量不得变成α-蒎烯。技术废物保留整股混合流质量及分析组分负荷，后者不得再次成为额外交换。

4. 覆盖原料、在制品、稀释油及已验收品的期初期末库存和真实批群。期初在制品继承既有前景工作及材料历史，不得当作无负荷新松脂。供方已含负荷只继承一次，仅追加新工作，不重复此前供方已含的熔脂或蒸馏。内部油和乳化层保留实物转移库存史，不是额外外购物或零信用残余出口。外购开车油和旧验收库存同新增松脂回收物分开追踪。完整清单要求继承和当期供方基准一致，不能仅凭期间净采购总量。

5. 本路线使用真实连接生产者外供的电力和水蒸汽。现场锅炉、燃料燃烧、火炬及 VOC 热破坏不属于该限定前景。实际存在时，不得将燃料或排放藏在身份不明的热投入内：应扩展并审查模型，逐一列出实际燃料、燃烧空气或氧气、水、排放物种、灰和有用热接口；或采用独立完整建模的真实公用工程或处理生产者，并匹配转移参考。直接环境水排放及外部捕集气处理同样需要真实接收方、介质和完整连接。

6. 整品质量、水、元素物种及内部转移账保持完整。对声明的归因清单，先在有实测时细分专用工序，再逐负荷采用已论证的决定性物理因果，仅对不可分剩余负荷使用真实可比厂门收入（jrc-ilcd-2010）。松节油与松香的质量比例本身不能证明热量因果。记录全部真实经济共功能及库存、等级、价值，包括确实销售的不合格品；废物处理仍连接真实接收方并带负荷。实际松香包装归于其功能，不创造包装共功能。内部回用油不是共功能、不避免外部产品且不增加 Q。不得通过乘分配系数抹去实物物种或废物来实现闭合；分配属于独立负荷账。不规定默认共产品比例、价格、替代或残余信用。

7. 逐容器材料核对：期初皮重 + 真实接收 = 期末皮重 + 交付皮重 + 返还皮重 + 废钢或损失，滞留油另列。松香包装产出与真实入场容器服务基准匹配。皮重流是实物转移，不是参考产量、新增共功能或自动信用。

8. 八项采集协议须在适用接口填入真实记录。数量、样本方法版本、状态转换、真实供方处理参考、未用证据、全部实际化学品物种、不确定度及完整期间覆盖必须可审查。必要方法未知、供方不匹配、质量库存物种未闭合或实物接口缺失均阻止数据集完整适用。机械一致性检查不证明科学批准或真实场址完整性。
