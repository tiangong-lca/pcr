## Route-evidence applicability clarification, 2026-10-28

The selected washing-before-independent-grading route remains a conditional narrow methodology, not an externally confirmed description of local practice. FAO 2009 describes sorting before washing; the FAO Peru article does not prove operation order. The explicit b_route_evidence rule requires actual farm/crop/lot event records, paired wash/sort timing and quantities, and operator confirmation before dataset eligibility is complete. Unknown order cannot be assumed, and an actually contrary order needs methodology review. This clarification preserves PCR identity, the selected product/state/gate and the accepted narrower mapping; it does not assert that missing field evidence has been obtained.
