# CPC 54613 semantic mapping decision

This individual decision accepts the narrower semantic relation after independent bilingual, projection, source, identity and measurement review. The positive edge and derived coverage require the separate reviewed integration transaction.

CPC 3.0 54613, “Burglar alarm system installation services”, includes construction-site installation and excludes monitoring/maintenance (85230). Source: [UNSD CPC 3.0 explanatory notes](https://unstats.un.org/unsd/classifications/Econ/Download/In%20Text/CPC_Ver_3.0_Exp_Notes_30Jun2025.pdf), PDF page 293.

The proposed canonical target is `pcr.constructions-and-construction-services.construction-services.burglar-alarm-system-installation-services` at `library/pcrs/constructions-and-construction-services/construction-services/burglar-alarm-system-installation-services`. Its relation is **narrower**: only first installation and commissioning of one single-panel hardwired normally-closed-zone intruder alarm with separate global tamper, keypad, detectors/contacts, external sounder and permanent standby battery, without supplied communication monitoring interface.

Wireless/hybrid/networked/addressable systems, fire/life-safety, cameras/access control, remote signalling/monitoring, telecommunications provision, periodic maintenance, upstream mains distribution and post-handover operation are excluded. This is not an assertion of complete subclass coverage.

The selected route receives components, confirms existing interfaces, mounts and terminates the system, configures and tests it, corrects/retests and ends at signed acceptance and user-control handover. Occupied-zone walk response, tamper, sounder, set/unset and restored normal state distinguish this service from conventional wired fire-alarm installation. Local utility cable works and whole-building PCRs have different outputs, interfaces and acceptance gates. Frozen catalog/scope screening found no existing material PCR owning this category.
