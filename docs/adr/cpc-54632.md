## Semantic boundary

First wall installation of a Class II basic intermittent axial extract fan on an already accepted sleeve, exterior grille, wall substrate and isolated fixed supply. Actual backplate fixings, local connection components, drilling or inspected prior fixing holes, isolated speed selection, cover retention, electrical checks, limited actual delivered-extraction testing against a prior project criterion, cleanup, corrections and signed handover define the route. The representative evidence is Vent-Axia 494229J0626 pp. 3–6: https://asset.eezybridge.com/nc/ba7b9546-29dd-40c4-87a7-885627281b87/494229.pdf .

Exclude Class I earthed fans, new core/sleeve/grille/circuit/isolator construction, timer/humidity/continuous variants, long ducts, heat recovery, air conditioning, routine use and subsequent maintenance. Rated flow is not delivered extraction; acceptance does not guarantee whole-building ventilation performance. The broad ventilation record is an empty legacy scaffold, not an overlapping material methodology.
